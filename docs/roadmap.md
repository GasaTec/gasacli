# Roadmap

## Milestone 1 — Working CLI + decision pipeline
- Scaffold TypeScript monorepo and `gasa` binary.
- Implement config, project registry and run storage.
- Build intent/risk classifier and structured planning contracts.
- Add tests for routing and permission enforcement.

## Milestone 2 — Second brain
- Connect local Obsidian/Markdown vault.
- Incremental indexing, SQLite FTS5, citations to note paths.
- Retrieval tests, sensitive-content controls, approval-based write proposals.

## Milestone 3 — Model router
- Provider registry and capability profiles.
- Budget ceiling, fallback, usage accounting and decision logs.
- Benchmark against fixed-model baselines.

## Milestone 4 — Orca execution
- Adapter and task DAG mapping.
- Worktree isolation, checkpoints and resume.
- Test/build/review quality gates.

## Milestone 5 — Extensibility
- Skill manifest, sandboxing, version pinning.
- Evaluate Ponytail 5, Caveman and other verified integrations.
- Documentation, install flow and future open-source readiness.

**Definition of MVP done:** one end-to-end task with grounded vault retrieval, routed execution, passing checks, recoverability and reported costs.
