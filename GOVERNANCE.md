# GasaCLI Governance

![GasaCLI logo](docs/img/logo.png)

GasaCLI is maintained in the open under the MIT License. This document describes the current decision process; it does not grant repository access or change GitHub settings.

## Maintainer

The repository owner and current maintainer is [@amaralzando](https://github.com/amaralzando). The maintainer is responsible for releases, repository configuration, security response and final decisions on project direction. A maintainer may delegate review or operational work, but remains accountable for access and release decisions.

## Contributions and decisions

Use issues for actionable bugs and proposals, and pull requests for reviewable changes. Discuss significant behavior or architecture changes in an issue before implementation. The maintainer reviews scope, compatibility, security, documentation and available checks before accepting a change. A review or CI pass does not waive security or ownership concerns.

Contributors must follow [CONTRIBUTING.md](CONTRIBUTING.md), the [Code of Conduct](CODE_OF_CONDUCT.md) and [Security Policy](SECURITY.md). Do not publish secrets, private user data or vulnerability details in public issues. The maintainer should use private vulnerability reporting when it is enabled; until then, follow the private contact instructions in `SECURITY.md`.

## Conduct and security contacts

Conduct reports should be sent privately to the maintainer through a contact method listed on the maintainer's GitHub profile. A dedicated project conduct email/contact is not configured by this document and must be established before launch. Security reports must use GitHub private vulnerability reporting when available; enabling that feature is an owner-only checklist item.

## Changes to governance

Propose governance changes in a pull request. The repository owner approves changes to maintainer roles, access, release authority and repository-level policy. See [`docs/launch-checklist.md`](docs/launch-checklist.md) for launch tasks that require owner action.
